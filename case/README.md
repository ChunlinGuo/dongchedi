## 如何生成更多案例

### 完整爬取零跑汽车
```bash
cd prototype
python main_full.py --brand-id 207 --with-config
```

### 爬取其他品牌示例
```bash
# 比亚迪
python main_full.py --brand-id 15 --with-config

# 小鹏汽车
python main_full.py --brand-id 182 --with-config

# 蔚来汽车
python main_full.py --brand-id 150 --with-config
```

### 参数说明
- `--brand-id`: 品牌ID（必需）
- `--with-config`: 爬取车型详细配置（包括智能化、辅助驾驶、电池等）
- `--limit-series N`: 限制只爬取前N个车系（用于测试）
- `--output-dir`: 指定输出目录（默认: ./data）

## 数据格式说明

所有Excel文件采用统一的多Sheet结构，便于数据分析和处理：

1. **品牌信息Sheet** - 1行记录，包含品牌ID、名称、爬取时间
2. **车系列表Sheet** - 每行一个车系，包含价格、懂车分等信息
3. **车型列表Sheet** - 每行一个车型，包含基本信息和价格
4. **智能化配置Sheet** - 长格式，每行一个配置参数（重点关注芯片数据）
5. **辅助驾驶配置Sheet** - 长格式，每行一个ADAS参数
6. **电池配置Sheet** - 长格式，每行一个电池相关参数
